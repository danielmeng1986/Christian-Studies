# 7. Roadmap

The roadmap describes near-term direction, not a commitment to build every possible feature.

## Version 1 — Foundation

- Establish the repository architecture and this Design Book.
- Adopt the per-book source, reading, notes, and metadata format.
- Use the first reference conventions.
- Begin one or more real reading projects to test the system.

## Version 2 — Refine through use

- Improve the reading workflow from observed practice.
- Strengthen reusable knowledge-page conventions and indexes.
- Clarify normalization and AI-provenance guidance where needed.

## Version 3 — Connect across books

- Add cross-book indexes where manual linking is no longer sufficient.
- Explore AI-assisted semantic linking with human review.
- Improve navigation while retaining readable, source-linked Markdown.

Each version should be revised only after real reading work identifies a clear need. The next milestone is to apply Version 1.0 to the first book and record the lessons it exposes.
