# 5. Reading Workflow

The standard study loop preserves the source while turning a book into a usable reading and knowledge-building project.

```text
Original source
      ↓
Normalize without overwriting the source
      ↓
Split into stable reading chapters
      ↓
Read and discuss a chapter
      ↓
Write book notes and journal reflections
      ↓
Update reusable knowledge pages
      ↓
Continue
```

## Responsibilities

Human judgment governs what is preserved, how a passage is interpreted, which questions matter, and which claims become durable knowledge. The reader remains responsible for theological conclusions and for checking sources.

AI may assist with normalization, questions, summaries, comparisons, candidate links, and drafting. AI output is working material, not source text. Label it clearly when retained, review it before relying on it, and connect it to the chapter or evidence from which it arose.

## Practical rhythm

1. Place supplied materials in the book's `Original/` directory and complete `Metadata/book.yml`.
2. Create or update `Reading/` files without changing the original files.
3. Read one stable chapter at a time; record questions and observations in `Notes/` or a dated `Journal/` entry.
4. When an observation is useful beyond the current book, add or improve a page in `People/`, `Concepts/`, `Scripture/`, or `Notes/` and link it back to its evidence.
5. Update progress only after the reader has completed the unit.

This loop is deliberately lightweight. The repository should accommodate different books and study habits without requiring a complex process.
