# 《追寻敬虔》Word 转 Markdown 规范

本规范供 AI 或转换脚本使用。权威源文件为 `Original/QFG Draft 20170911 20211005.doc`；现有 Markdown 只作为仓库包装方式与人工校订案例，不能反向覆盖 Word 原稿中的内容和语义样式。

## 一、权威顺序

1. 正文文字、段落边界、章节边界、标题级别、缩排引文、斜体及脚注：以 Word 为准。
2. 文件路径、YAML 元数据、章节文件命名、`References` 目录和相对链接形式：以仓库现状为准。
3. 第 4 章人工修订稿：作为 Markdown 表达范例；若它与 Word 的明确样式冲突，记录差异并以 Word 为准。
4. 不擅自现代化标点、繁简转换、修订译名、润色、补写或删节。可疑错字只报告，不静默修正。

## 二、章节切分

- 以段落样式 `heading 1` 且文本精确匹配“第N章”的段落作为章节起点。
- 紧随其后的第二个 `heading 1` 是章名；合并为一个 Markdown 一级标题：`# 第N章：章名`。
- 遇到下一个 `heading 1` 的“第N章”“第N部份”或“第N部分”即停止；不得把下一部分或下一章标题带入当前文件。
- 删除由版面需要产生的章首空段和前导制表符，不删除有文字的段落。

每章文件固定开头如下：

```markdown
---
book: 追寻敬虔
chapter: NN
source_file: Original/QFG Draft 20170911 20211005.doc
source_location: "第N章，Word 文档第X–Y页"
---

# 第N章：章名

> 来源定位：原始文档 第N章，Word 文档第X–Y页。
```

### Word 页码定位

- 页码采用 Microsoft Word 完成分页后显示的**文档物理页码**，用于回到原稿定位；它不等同于页脚中印刷的书页编号。
- 在 Word 中重新分页后，按 `heading 1` 样式查找目标“第N章”和下一章标题。必须限定标题样式，以排除目录中同名条目。
- 本章页码范围为“本章正文标题所在页”至“下一章正文标题所在页减一”。第二十章以 Word 统计的文档总页数为结束页。
- 不使用 LibreOffice 导出的 PDF 推断这一页码。此旧版 `.doc` 在 LibreOffice 中会因字体和版式兼容问题重新流动，页数与 Word 不一致。
- 将核验结果传给转换脚本的 `--source-pages START-END`。若尚未完成 Word 核验，应写“尚未核验 Word 文档页码”，不得声称源文件没有稳定页码。
- 第五章的已核验范例：目录中的“第五章”在第 8 页；正文 `heading 1`“第五章”在第 97 页；正文 `heading 1`“第六章”在第 117 页；因此第五章范围是第 97–116 页。

## 三、Word 段落样式映射

| Word 样式 | Markdown | 说明 |
|---|---|---|
| `heading 1` | `#` | 章号与章名合并；部分/下一章标题是切分边界 |
| `heading 2` | `##` | 章内大分节，如“壹 福音派健将” |
| `heading 3` | `###` | 大分节下的小节，如“1.1 ……” |
| `heading 4` | `####` | 更低层主题，如“靈魂的大夫” |
| `內文縮排` | `> ` | 独立引文；连续段落保持在同一引文块内，段间用仅含 `>` 的空行 |
| `Normal` | 普通段落 | 一段对应一个 Markdown 段落 |
| `問候` | 普通段落 | 此稿中是误用/遗留样式，不表示特殊语义 |

不得仅凭字号、字体或肉眼位置猜标题。若出现表中没有的新段落样式，先报告样式名、上下文和数量，再决定映射。

## 四、行内样式

- Word 直接斜体或实际带斜体属性的字符样式 → `*文字*`。主要用于英文书名、论文名、拉丁词和英文术语。
- Word 直接粗体或实际带粗体属性的字符样式 → `**文字**`；粗斜体 → `***文字***`。
- 合并相邻且格式相同的 run，避免 `*一小段**又一小段*`。
- `labellist`、`textblue`、`st`、字体名称、字号、颜色、校对痕迹等在此原稿中并不稳定，不映射为 Markdown 强调。
- 保留原文的全角/旧式中文标点、方括号补文、波浪号年代写法和英文拼写；只清除用于版面缩排的段首 tab。

## 五、引文与列表

- `內文縮排` 是语义性长引文，不可当作普通正文。
- 连续缩排段落应处于同一个 Markdown blockquote 中。
- 缩排段落本身若以 `1.`、`2.` 等开头，写成 `> 1. ...`，让 Markdown 在引文内部呈现有序列表。
- 普通正文中内嵌的“第一、第二……”不擅自拆成列表；以 Word 段落边界为准。

## 六、脚注

- 每章单独创建 `References/Footnotes-NN.md`，一级标题为 `# Footnotes-NN`。
- 按本章正文中首次出现的顺序重新编号普通脚注，从 1 开始；不要沿用 Word 全书级脚注 ID。
- 正文链接写作 `[1](../../References/Footnotes-NN.md#1)`；相对路径必须从实际章节目录计算，不能硬编码目录深度。
- Word 的自定义符号脚注（如 `*`、`**`、`+`）不进入普通编号序列。按出现顺序建立 `## 译者注1`、`## 译者注2`，正文分别链接为 `[*](...#译者注1)`、`[**](...#译者注2)`。
- 脚注正文保留其内部段落。脚注首段中的自定义符号只作为标记，写入 `References` 时移除该符号，避免重复。
- 每个正文脚注引用必须有且只有一个目标标题；每个脚注标题必须至少被正文引用一次。

2. 把分离的“第四章”和章名合成一级标题。

5. 将原来裸露在正文末尾的脚注序号改为可点击链接，并新增逐章脚注文件。

## 八、自动与人工校验门槛

转换后必须全部通过：

1. **边界**：文件只含目标章，不含下一部分/下一章标题。
2. **页码**：`source_location` 与 Word 中正文章标题和下一章标题的物理页码一致；不得误用目录页码或 LibreOffice/PDF 页码。
3. **标题**：Word 各级 heading 的数量与 Markdown 对应级别数量一致（章首两个 `heading 1` 合并为一个 `#`）。
4. **段落**：每个有文字的 Word 正文或缩排段落在 Markdown 中恰好出现一次；不得合并、拆写、摘要。
5. **引文**：`內文縮排` 的数量与生成的引文段落数量一致。
6. **脚注**：引用数、脚注标题数和 Word 本章唯一脚注 ID 数一致；普通编号连续；译者注不占普通编号。
7. **链接**：逐一验证 Markdown 链接目标文件存在，且锚点标题存在。
8. **行内格式**：抽查 Word 的所有斜体/粗体 run；相邻 run 已合并，没有遗失或多余强调。
9. **文本**：去除 Markdown 标记和脚注链接显示文本后，与 Word 源段落逐段比对；差异必须能由规定的结构转换解释。
10. **仓库安全**：保留用户的无关改动，不修改 Word 原稿，不提交 Office 临时锁文件。
