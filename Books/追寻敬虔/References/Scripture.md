# Scripture

Scripture citations remain as they appear in the source text. Do not modernize or replace an imported quotation silently.

For Scripture text newly displayed beside this book, use the repository corpus's `cuv-s` (新标点和合本简体) as the default translation unless the source or user names another version. Keep the original traditional-Chinese citation label visible; the shared mapping accepts both forms, so `路4:23` resolves to `LUK 4:23` and `來11.39` resolves to `HEB 11:39` before lookup in CUV-S.
